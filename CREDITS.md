# Credits

## Art: the Tuxemon project
All tilesets, character sprites, monster sprites and portraits in `public/assets/`
come from [Tuxemon](https://github.com/Tuxemon/Tuxemon), the free and open-source
monster-catching RPG, made by many contributors.

Most of the art is licensed **CC BY-SA 4.0** (some pieces are CC0 / CC BY 3.0 / CC BY-SA 3.0).
The full per-asset attribution list is in
[`public/assets/TUXEMON_ATTRIBUTIONS.md`](public/assets/TUXEMON_ATTRIBUTIONS.md).

Building stamps (`src/data/stamps.json`) are tile arrangements cut from Tuxemon's maps
(`spyder_paper_town`, `taba_town`, `spyder_candy_port`), so they carry the same licenses.

Because of CC BY-SA, any modified versions of these assets must be shared under the same license.

## Code
Game code in `src/` is original (no Tuxemon code is used).
